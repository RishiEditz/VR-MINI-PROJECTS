# To-do List (Exploring Mini Projects, Day 3)

A to-do list app built with plain HTML, CSS and JavaScript. No libraries, no build step.

## Files

- `index.html` - page structure
- `style.css` - colours, animated background, responsive layout, reduced-motion support
- `script.js` - add, tick, edit, reorder, priority, filter and clear logic

## Run it

Open `index.html` in any modern browser. Nothing to install.

## Features

- Add a task with a priority (Low, Medium, High)
- Tick a task off, with a small confetti burst
- Double-click a task to edit it; press Enter to save or Escape to cancel
- Move a task up or down with the buttons, or with Alt + Up or Down
- Filter by All, Active or Done
- Clear completed tasks in one tap
- Tasks are saved in the browser (localStorage), so they stay after a reload

## Notes

- Works on phones, tablets and desktops.
- Respects the "reduce motion" setting in the operating system.
